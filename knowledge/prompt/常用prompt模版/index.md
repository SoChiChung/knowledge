# 汉化图


**制作步骤**
下面整理成一个通用「足球数据图表汉化改稿提示词模板」。以后你给任何类似 FPL 数据图、排行榜、统计表，都可以直接套用。

---

## 足球数据图表汉化改造提示词模板

请根据原图进行汉化重绘。

### 一、整体原则（不可改变）

1. **保持原图信息结构不变**

* 保留原图所有表格、排名顺序、数据数字、价格分组、颜色标识。
* 不改变任何统计数据。
* 不增加、不删除任何球员。
* 不调整球员排名。
* 不修改百分比、积分、次数等数值。

2. **保持原图视觉风格**

* 保留原图整体布局和信息图属性。
* 可以优化清晰度、排版和视觉美观度。
* 风格调整为：

  * 可爱手账风；
  * 柔和 pastel 配色；
  * 轻微赛璐璐插画质感；
  * 圆角表格；
  * 手账贴纸、胶带、小装饰元素。

3. **保持比例**

* 默认保持原图 3:4 竖版比例。
* 如果文字汉化后空间不足，可以适当增加高度。
* 不允许压缩文字导致无法阅读。

---

## 二、绝对不能修改的内容

### 1. 球员英文名必须保留

所有球员名字保持英文原样。

例如：

正确：

```
VAN DIJK
GABRIEL
GUEHI
PEDRO PORRO
```

错误：

```
范戴克
加布里埃尔
格伊
佩德罗·波罗
```

不要翻译球员姓名。

---

### 2. 队徽必须完全按照原图

这是重点：

* 原图中的俱乐部徽章必须保留。
* 不允许重新绘制其他队徽。
* 不允许根据球员名字猜测球队。
* 不允许替换成其他球队 Logo。
* 不允许简化成类似图案。

例如：

如果原图 Guehi 使用 Manchester City 队徽，则必须保持 Manchester City 队徽。

如果原图球员属于其他球队，即使现实信息变化，也以原图为准。

---

### 3. 数据字段保持原含义

不要修改：

* Total Starts 数值
* DEFCON hit rate 数值
* DEFCON p/start 数值
* Attacking returns 数值

所有数字必须完全一致。

---

## 三、需要汉化的内容

### 1. 标题汉化

例如：

原文：

```
DEFCON LEADERS (DEFENCE)
```

改为：

```
DEFCON 领先者（防守）
```

注意：

* DEFCON 保留英文。
* 不翻译成其他类似词。

---

### 2. 表头汉化

统一使用以下翻译：

| 原文                | 中文         |
| ----------------- | ---------- |
| Total Starts      | 总出场次数      |
| DEFCON hit rate   | DEFCON命中率  |
| DEFCON p/start    | DEFCON关键球员 |
| Attacking returns | 进攻回报       |

要求：

* 中文必须准确。
* 不使用机器直译。
* 保证没有错别字。

---

### 3. 联赛括号汉化

球员名字后面的括号信息：

规则：

* 英文球员名保持不变。
* 括号里的联赛名称翻译成中文。

例如：

```
VUSKOVIC (Bundesliga)
```

改：

```
VUSKOVIC（德甲）
```

---

对应规则：

```
Bundesliga → 德甲
Serie A → 意甲
Ligue 1 → 法甲
Champ → 英冠
Premier League → 英超
La Liga → 西甲
```

特别注意：

Champ 是 Championship（英格兰冠军联赛），必须翻译为：

```
英冠
```

不是：

```
中冠
```

---

## 四、版权信息

原图作者信息必须保留：

```
@FPL_TomHadley
```

位置可以微调，但不能删除。

不要添加其他来源信息。

---

## 五、字体和文字要求

* 中文字体需要清晰易读。
* 不允许出现：

  * 错别字；
  * 生硬翻译；
  * 简体字错误；
  * 字符乱码。

生成前需要人工检查：

标题：
「DEFCON 领先者（防守）」

表头：
「总出场次数」
「DEFCON命中率」
「DEFCON关键球员」
「进攻回报」

以上文字必须完全正确。

---

## 六、最终生成要求总结

请制作一张：

「FPL 足球数据统计汉化信息图」

要求：

* 保留原图所有数据；
* 保留英文球员名；
* 保留原图队徽；
* 保留作者署名；
* 汉化标题、表头、联赛说明；
* 使用可爱手账风 + 赛璐璐质感；
* 保持3:4竖版；
* 确保中文无任何错误；
* 不自行修改任何原始足球信息。

---

这个模板后面不仅适用于 DEFCON，也适用于 FPL 价格表、球员推荐表、Fixture Difficulty、队伍数据排行等类型的图片。
