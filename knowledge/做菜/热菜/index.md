# 热菜大全

## 窝蛋香菇肉碎西洋菜

**制作步骤**
1. 预处理食材：西洋菜去掉老梗、黄叶，清水浸泡冲洗去除涩味；干香菇温水泡发，挤干水分切成小丁；猪肉剁成肉碎；生姜切丝、胡萝卜切小丁备用。
2. 煸炒底料：锅中倒入少许食用油，下姜丝、香菇丁小火翻炒，炒出香菇鲜香，再倒入肉碎，中火翻炒至肉碎完全散开、变色。
3. 熬煮底汤：放入胡萝卜丁翻炒片刻，加入足量清水，开大火烧至沸腾。
4. 烫煮西洋菜：水开后放入西洋菜，滚煮1-2分钟至菜叶变软。
5. 基础调味：放入适量食盐、鸡粉或松鲜鲜搅拌均匀。
6. 窝蛋焖制：调至最小火，在汤面空位打入完整鸡蛋，不要搅动，盖上锅盖焖至蛋清凝固，想要溏心蛋黄可缩短焖煮时间。
7. 增香出锅：淋入蒜头油拌匀，既可直接喝汤，也能搭配面条食用。

**食材原料**
- 西洋菜：300g
- 猪肉碎：150g
- 干香菇：3～4朵
- 鸡蛋：1个
- 生姜：少许
- 胡萝卜：少量
- 蒜头油、食盐、鸡粉（松鲜鲜）、食用油：适量

## 芥末虾

**制作步骤**
1. 鲜虾剪去虾须、虾头尖刺，开背去除虾线，洗净后沥干表面水分。
2. 腌制虾肉：虾中加入盐、鸡蛋黄、胡椒粉、料酒、干淀粉抓拌均匀，腌制10分钟入味。
3. 锅中倒油烧至六成油温，下入腌好的虾，炸至外壳金黄酥脆后捞出控油。
4. 调芥末酱汁：碗中放入沙拉酱、黄芥末、炼乳、蜂蜜芥末酱，充分搅拌混合顺滑。
5. 将炸好的虾倒入酱汁内翻拌，让每只虾均匀裹满酱汁即可装盘。

**食材原料**
- 大虾：300g
- 鸡蛋黄：1个
- 沙拉酱：4勺
- 黄芥末：适量
- 炼乳：1勺
- 蜂蜜芥末酱：半勺
- 玉米干淀粉：适量
- 料酒、食盐、白胡椒粉、食用油：适量

## 玫瑰鸡翅

**食材准备**
- 鸡翅 5只（提前解冻）
- 盐
- 可食用玫瑰花瓣
- 白糖
- 清水
- 玉米淀粉
- 牛油（黄油）
- 蜜糖
- 玫瑰花粉
- 玫瑰油
- 调味白醋
- 欧芹（蕃茜）

<br>

**制作步骤**
- **第一阶段：腌制鸡翅**
  1. 鸡翅加1汤匙盐腌制5分钟，冲洗干净后彻底抹干水分。
  2. 锅中放入1汤匙玫瑰花瓣、1汤匙糖、1汤匙盐、1杯水，开火煮沸。
  3. 煮好的玫瑰糖水放凉，倒入搅拌机打碎搅匀，制成玫瑰腌料。
  4. 鸡翅浸入玫瑰腌料，腌制4小时入味。

- **第二阶段：气炸鸡翅**
  1. 腌好的鸡翅取出，表面均匀裹一层玉米淀粉。
  2. 空气炸锅180℃，鸡翅表面喷油，先炸5分钟。
  3. 取出翻面，再次喷油，继续180℃炸7分钟。

- **第三阶段：熬制玫瑰酱汁、裹酱成品**
  1. 熬玫瑰酱汁（全程保持小火操作）：
     1. 锅内放入1汤匙牛油融化
     2. 加入1汤匙蜜糖、1汤匙玫瑰花粉翻炒混合
     3. 熬至酱汁浓稠后，下入半茶匙玫瑰油拌匀
     4. 最后放1茶匙调味白醋，搅拌均匀关火
  2. 把炸好的鸡翅倒进酱汁锅，翻拌至每块鸡翅均匀裹满酱汁。
  3. 装盘后撒欧芹碎、玫瑰花瓣装饰，完成。
